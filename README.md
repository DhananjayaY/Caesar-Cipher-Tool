# Caesar Cipher Encryption Tool

## Overview

A simple GUI-based Caesar Cipher application developed using Python. The tool allows users to encrypt and decrypt text by shifting characters based on a user-defined key.

This project was created to explore the fundamentals of classical cryptography, encryption techniques, and desktop application development.

## Features

* Text encryption using Caesar Cipher
* Text decryption using Caesar Cipher
* Custom shift key selection
* User-friendly GUI built with Tkinter
* Instant encryption and decryption results

## Technologies Used

* Python
* Tkinter

## Learning Outcomes

* Cryptography fundamentals
* Encryption and decryption techniques
* Python programming
* GUI development with Tkinter
* User input validation

## Disclaimer

This project is intended for educational purposes only. The Caesar Cipher is a classical encryption technique and should not be used for securing sensitive information.
